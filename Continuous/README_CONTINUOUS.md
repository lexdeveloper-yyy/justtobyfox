# Continuous

**«Continuous»** — альтернативный опенинг на основе **`2. beginning.flp`** (*Beginning*, `138.0 BPM`, `4/4`, `PPQ = 96`, `33` такта = `0:57.39`, тональность звучания `B major` / запись в `C major` с `pitch_shift = -100`), где лейтмотив *Don't Forget* (`0:06 — 0:38`) полностью заменён на светлую оркестровую тему **`Tale`** (*His Theme / Memory / Undertale*), а финал с лейтмотивом *Once Upon a Time* и ко́дой (`0:38 — 0:57`) сохранён **полностью неизменным (1-в-1 до последнего тика)**.

---

## Состав релиза (`Continuous/`)

1. **`Continuous/Continuous.flp`** — основной проект на оригинальных SoundFont-инструментах `2. beginning.flp` (`SGM-V2.01.sf2` + `squidfont_orchestral.sf2` на `CH 02 vins`), с отвязанным референсом `CH 00` и чистым встроенным микшером FL Studio (**`0` сторонних VST / `Fruity Wrapper`**).
2. **`Continuous/Continuous (Universal).zip`** *(и распакованная папка `Continuous/Continuous (Universal)/`)* — универсальный Zipped Loop Package без `squidfont_orchestral.sf2` (`CH 02 vins` перенесён на `SGM-V2.01.sf2 Strings`) с приложенным импульсом `IMP Lex - Close Warm Room.wv` для реверберации.
3. **`Continuous/Continuous.mid`** — синхронизированный MIDI-файл в звучащей тональности (`B major`, `138.0 BPM`, `PPQ = 96`, `10` инструментальных дорожек).

## Автоматическая проверка качества

- **Побитовая проверка концовки (`B22.00 — B33.00` / `0:38 — 0:57`)**: `53 / 53` ноты (`celesta`, `clarinet`, `strings`, `piano`) совпадают с `2. beginning.flp` по тикам, длительностям, высотам, велосити, панораме и флагам на **100%**.
- **Гармонический аудит (`B04 — B22`)**: `0` перекрытий нот, `0` клип-коллизий на дорожках, `0` резких диссонансов на малую секунду.
- **Проверка структуры FLP**: `13 / 13` именованных 3-событийных паттернов (`New`, `Name`, `Notes`), `13 / 13` клипов плейлиста с точными офсетами `000080bf000080bf` (`start_offset = -1.0, end_offset = -1.0`), `CH 00` отвязан и замьючен, **`0` `Fruity Wrapper` сторонних VST** (штатный `Fruity Convolver` на `INS 5 trumpet` + штатные `Parametric EQ 2`, `Delay 2`, `Limiter`).
